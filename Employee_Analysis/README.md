# Employee Analysis – SQL Project

## Project Overview

This project analyzes employee data using SQL and MySQL.

The analysis focuses on employee salaries, departments, hiring trends, salary classifications, and department-level statistics.

## Objectives

- Analyze employee distribution across departments
- Calculate average, minimum, and maximum salaries
- Identify the highest-paid employees
- Compare employee salaries with overall and department averages
- Analyze hiring trends by year
- Rank employees based on salary
- Practice SQL joins, subqueries, CASE statements, and window functions
